Keterangan

  • Koneksi Fiber / Uplink (Trunk VLAN)
  • Koneksi LAN (Access)
  • Koneksi Wireless
  • ((•))Akses WiFi
  • Kamera CCTV
  • Server
  • PC / Client
  • Internet

Konsep Pengkabelan

  • Link MikroTik → Core Switch dan Core → tiap switch gedung pakai TRUNK 802.1Q (bawa beberapa VLAN).
  • Port ke perangkat akhir (PC, CCTV, NVR) pakai mode ACCESS sesuai VLAN-nya.
  • Access Point menyiarkan beberapa SSID per VLAN; port ke AP pakai mode TRUNK.
  • Switch managed dipakai di Core dan tiap gedung untuk kontrol VLAN.
  • Penomoran VLAN & IP disesuaikan per lokasi/fungsi, bukan sekadar lokasi fisik.
  • UPS dipasang untuk perangkat inti (MikroTik, Core Switch, NVR).

Manfaat Topologi Ini

  • Jaringan lebih aman & tersegmentasi
  • Mengurangi broadcast & gangguan antar VLAN
  • Mudah dikelola dan dikembangkan
  • Cocok untuk lingkungan multi-gedung
  • Mendukung Server, CCTV, dan sistem lain sekaligus
  • Siap untuk kebutuhan penambahan gedung/VLAN
